# 今日热榜 · HotBoard

> 全网热点 · 实时聚合 —— 一个纯静态、零后端、零构建的多平台热榜聚合页。

![榜单平台](https://img.shields.io/badge/榜单平台-46-e8442e)
![分类](https://img.shields.io/badge/分类-5-f59e0b)
![构建](https://img.shields.io/badge/build-none-lightgrey)
![主题](https://img.shields.io/badge/主题-亮色%20%7C%20暗色-blueviolet)
![协议](https://img.shields.io/badge/license-MIT-green)

实时聚合 **微博、知乎、百度、B 站、X、GitHub、Hacker News、BBC、纽约时报、澎湃新闻** 等 **46 个平台**的热榜与新闻头条，按「综合热搜 / 科技开发 / 海外视野 / 新闻资讯 / 影音娱乐」五大分类展示，默认每 5 分钟自动刷新。

项目由原生 HTML、CSS 和 JavaScript 编写，没有后端、数据库与构建步骤。数据在浏览器端读取第三方公开接口或公开页面；页面没有服务端存储，仅在当前标签页会话中缓存榜单数据。

---

## 功能特性

- **46 个榜单 · 5 大分类**：综合 9、科技 10、海外 11、新闻 7、娱乐 9，支持页签一键筛选。
- **官方图标**：本地存放各平台官方图标；图标缺失或加载失败时，自动回退为品牌色字符徽标。
- **实时滚动播报**：顶部跑马灯汇聚各榜头条，悬停暂停。
- **自动与手动刷新**：每 5 分钟自动刷新并显示倒计时；自动刷新只刷新已加载卡片，手动刷新全部会加载所有榜单；切回标签页时若数据已过期会自动补刷。刷新会等待在途请求全部结束，提示中汇总成功和失败数量，并点名失败来源；搜索或免责声明弹窗打开时暂停自动刷新。
- **按需加载**：首屏卡片在进入视口时请求，滚动、切换分类、展开分类或搜索时再补载其余榜单；请求最多 6 路并发，刷新按钮和自动刷新不会重叠执行。切换地区会中止旧请求并让新请求排队。
- **会话缓存**：按榜单和地区缓存 5 分钟；命中缓存先渲染，过期时后台刷新，刷新失败保留缓存数据并标记「缓存」；缓存读取会校验条目结构，跨日数据会显示日期。
- **按需渲染**：每张卡片初始只渲染前 10 条，展开时补全；收起列表或清空搜索后回收额外 DOM。搜索直接基于已加载数据统计，不再批量展开每张卡片。视口外卡片通过 `content-visibility` 跳过渲染，未进入视口的骨架动画暂停。
- **全局搜索**：跨全部榜单过滤标题关键词，进入搜索时临时切到「全部」页签并提示搜索范围，补载未加载榜单；搜索中切换分类只统计当前分类的可见结果，清空后恢复到最近选择的页签（搜索过程中切换的分类会更新该选择）。无命中的卡片和分类会隐藏，结果随加载补齐；全部加载完仍无结果时显示空状态，命中在首屏 10 条之外时卡片会提示具体位置。按 <kbd>/</kbd> 聚焦搜索框，搜索框聚焦时按 <kbd>Esc</kbd> 清空；输入带 120ms 防抖，结果更新按帧合并，加载期间显示「搜索中」状态。
- **列表展开**：大部分卡片默认展示 10 条，初始只渲染前 10 条 DOM，展开时补全；收起时立即回收额外 DOM。刷新会保留已展开状态和列表焦点；搜索命中可能在首屏 10 条之外，此时会提示命中位置并显示「展开全部（匹配 N 条）」。X 趋势与 App Store 固定展示所选地区的 Top 10，不提供展开全部。
- **分类折叠**：点击「综合热搜 / 科技开发 / 海外视野 / 新闻资讯 / 影音娱乐」分类大标题，可收起或展开该分类下的整组榜单，箭头同步指示状态；搜索时自动展开被收起的分类，清空搜索后恢复原状态。
- **地区切换**：X 趋势支持全球及 62 个国家/地区的实时趋势，App Store 支持 34 个国家和地区的免费榜，二者默认均为美国；在卡片底部切换地区后仅刷新当前榜单，自动刷新沿用所选地区。
- **官方入口**：点击榜单名称可跳转到该平台的官方热榜页。
- **深色 / 浅色主题**：首次访问跟随系统偏好，可手动切换并记忆到 `localStorage`；内联脚本预渲染，避免刷新时闪烁。手动切换使用 View Transition 播放约 320ms 的主题交叉淡化，切换期间抑制逐元素过渡；不支持时降级为瞬时切换。`color-scheme` 与 `theme-color` 会随主题同步，原生控件和移动端浏览器配色保持一致。
- **免责声明弹窗**：页脚「免责声明」按钮打开原生 `<dialog>` 信息框，弹窗内包含数据来源、使用提示与责任说明；支持 <kbd>Esc</kbd>、点击遮罩、关闭按钮和「我知道了」关闭；打开时锁定页面滚动，关闭后焦点回到触发按钮。
- **响应式布局**：960 / 860 / 560 三个断点，适配桌面、平板和手机，支持移动端安全区。
- **阅读细节**：骨架屏、滚动浮现、加载失败重试、离线与恢复联网提示、回到顶部 / 底部悬浮按钮；桌面端预留右侧净空，移动端信息流保持满宽、按钮直接悬浮；触屏轻触顶部跑马灯可暂停滚动；搜索时任意来源失败或非搜索状态多个来源失败时显示可关闭的提示条，可一键重试失败榜单。
- **站点状态**：页脚显示站点运行时长和本次页面加载耗时。
- **纯静态**：原生 HTML / CSS / JavaScript，无框架、无构建步骤、无后端运行时依赖；字体子集与图标均为本地静态资源。

## 项目结构

```
hotboard/
├── index.html   # 页面结构、CSP、主题预渲染脚本、免责声明弹窗
├── hot.css      # 主题变量、布局、卡片、弹窗与响应式样式
├── hot.js       # 数据抓取、缓存、渲染、搜索、刷新与页面交互
├── icons/       # 46 个平台的官方图标（PNG / SVG / JPG / ICO）
├── fonts/       # 自托管字体子集、字符清单与 OFL 许可证
├── scripts/
│   ├── check.mjs      # 零依赖：CSP、字体子集、榜单配置、图标与语法检查
│   ├── build-fonts.mjs # 重新生成 ZCOOL 子集并下载 JetBrains Mono
│   └── font-text.mjs  # 从配置提取使用展示字体的文案字符
├── .github/
│   └── workflows/check.yml # push / PR 自动运行检查
├── .gitignore   # 忽略依赖、环境文件、日志和系统临时文件
└── README.md    # 项目说明
```

> `index.html` 通过相对路径引用 `hot.css`、`hot.js`、`icons/` 与 `fonts/`，部署时请保持目录结构不变。

### 数据说明

- 所有请求均由浏览器直接发起，项目没有服务端存储、转发或商业使用榜单内容；榜单仅在当前标签页会话缓存。
- 豆瓣官方页面未开放 CORS，因此通过 Redocly 公共代理读取；豆瓣榜单展示评分，不展示热度值。
- X 趋势读取 getdaytrends 的全球或所选国家/地区趋势页（同样经 Redocly 代理），默认展示美国趋势，卡片底部可切换地区，条目按当前排名展示并跳转至 X 搜索结果；X 未提供浏览器可直接调用的官方趋势接口，因此不展示热度值。
- App Store 榜单读取 iTunes RSS 的分区免费榜（经 Redocly 代理），默认展示美国区，卡片底部可切换商店地区，固定展示 Top 10，不展示热度值。
- BBC、纽约时报、卫报、半岛电视台、NPR、德国之声通过官方 RSS 展示最新报道，顺序由来源 feed 决定，并非平台全站热度排行，也不展示热度值。
- 新浪热榜展示 `top_num` 热度；网易新闻与澎湃新闻使用平台公开热榜接口，不展示热度值；中国新闻网通过官方即时新闻 RSS 展示最新报道。
- Product Hunt、懂球帝等榜单不显示热度值。
- Codelife 是第三方聚合，榜单快照和更新频率由服务方决定，可能滞后于平台官方榜；使用 Codelife 的卡片会在时间旁显示「第三方」标签，时间文案为「抓取于」，表示客户端抓取时间而非来源更新时间。Codelife 失败时卡片显示失败提示和「重新加载」按钮，当前没有可用的公开备源。
- 第三方接口与公共 CORS 代理可能限流、改版或短时不可用，属于外部依赖限制；重新加载通常可以恢复。

## 快速开始

### 直接打开页面

保持 `index.html`、`hot.css`、`hot.js` 和 `icons/` 目录的相对位置，双击 `index.html` 即可预览。部分浏览器对本地文件发起的跨域请求限制较多，建议使用本地静态服务器。

### 本地静态服务器

```bash
# 在项目目录下执行任一命令
python -m http.server 8080
# 或
npx serve .
```

浏览器访问 `http://localhost:8080/`。

### 项目检查

```bash
node scripts/check.mjs
```

检查 CSP 内联脚本哈希、所有 API 主机覆盖、字体文件与子集文本一致性、字体预载、`SHOW` 与折叠 CSS 一致性、榜单数量与唯一 id、分类、默认地区、图标映射与 `hot.js` 语法；CI 在 push / pull request 时自动执行同一脚本。

### 部署

**GitHub Pages**

1. 将仓库推送到 GitHub。
2. 进入仓库 **Settings → Pages**。
3. Source 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，保存。
4. 部署完成后访问 `https://<用户名>.github.io/<仓库名>/`。

也可直接部署到 Vercel、Netlify、Cloudflare Pages 等静态托管平台，无需配置构建命令，发布目录为项目根目录。

## 自定义配置

主要配置集中在 `hot.js` 顶部。

### 榜单

编辑 `SOURCES` 数组添加或调整榜单：

```js
{
  id: 'weibo',
  cat: 'hot',
  name: '微博热搜',
  char: '微',
  color: '#e6162d',
  sub: '随时随地发现新鲜事',
  cid: 'KqndgxeLl9',
  home: 'https://s.weibo.com/top/summary'
}
```

| 字段 | 必填 | 说明 |
| :--- | :---: | :--- |
| `id` | 是 | 唯一标识，同时对应 `ICONS` 中的图标键 |
| `cat` | 是 | 所属分类 ID，需在 `CATS` 中定义 |
| `name` | 是 | 榜单名称 |
| `char` | 是 | 图标加载失败时显示的字符徽标 |
| `color` | 是 | 品牌色，用于徽标边框、字符与阴影 |
| `sub` | 是 | 卡片副标题 |
| `cid` | 二选一 | Codelife 榜单 ID，走主源时填写 |
| `api` | 二选一 | 自定义数据源标识，当前支持 `hn`、`devto`、`douban`、`x`、`appstore`、`rss`、`sina-hot`、`netease`、`thepaper` |
| `feed` | 否 | `api: 'rss'` 时必填，媒体官方 RSS 地址 |
| `regions` | 否 | 可选地区列表；配置后卡片底部显示地区选择器，X 与 App Store 使用该字段 |
| `region` | 否 | 默认地区 ID，需存在于 `regions` 中 |
| `nohot` | 否 | 为 `true` 时不展示热度值 |
| `home` | 是 | 平台官方热榜地址，点击卡片标题时跳转 |

每个榜单需要提供 `cid` 或 `api` 之一。新增自定义数据源时，还需在 `loadSource()` 中补充对应分支。

### 图标

将图标文件放入 `icons/`，并在 `ICONS` 映射中登记：

```js
const ICONS = {
  weibo: 'weibo.svg',
  // ...
};
```

图标加载失败时页面会自动切换到字符徽标，不影响榜单数据展示。

### 分类与刷新

- **分类**：在 `CATS` 中追加 `{ id, name, en }`，页签、分类标题和榜单数量会自动生成。
- **自动刷新间隔**：修改 `REFRESH_MS`，默认 `5 * 60 * 1000`（5 分钟，同时作为会话缓存的刷新阈值；旧缓存仍会作为失败回退保留并显示日期）。
- **默认展示条数**：修改 `SHOW`，默认 `10`；同时作为 X 趋势与 App Store 的抓取条数。RSS 与新浪、网易、澎湃热榜单卡最多读取 30 条；其余条目保留在内存中，展开或搜索时再渲染。
- **地区列表**：X 趋势的地区在 `X_REGIONS` 中维护，App Store 的地区在 `APP_REGIONS` 中维护。
- **运行时长起始时间**：修改 `SITE_BIRTH`，默认 `2026-07-20`。
- **接口地址**：`API_CODELIFE`、`API_HN`、`API_DEVTO`、`API_DOUBAN`、`API_X`、`API_ITUNES`、`API_SINA_HOT`、`API_NETEASE`、`API_THEPAPER` 等常量集中在 `hot.js` 顶部。

## 交互说明

- **搜索**：仅匹配已加载榜单的标题文本；搜索时会补载未加载榜单、补全已加载卡片的条目并过滤不匹配项，无命中结果的卡片变暗，被收起的分类会自动展开。
- **搜索与列表折叠**：折叠卡片在搜索状态下最多展示前 10 条命中，按钮显示「展开全部（匹配 N 条）」；展开后展示该卡片的全部命中。清除搜索后，标题命中状态和分类折叠状态恢复，未主动展开的卡片回收额外 DOM。
- **展开列表**：普通卡片初始只生成前 10 条 DOM，内容超过 10 条时显示「展开全部（共 N 条）」，展开时补全并切换为「收起榜单」；收起时立即回收额外 DOM。
- **收起分类**：点击分类大标题可收起或展开该分类的整组榜单；收起后标题仍保留，箭头旋转指示状态，展开时补载该分类。
- **切换地区**：X 趋势与 App Store 卡片底部有地区选择器，切换后优先读取该地区缓存，缺失或过期时再请求；卡片副标题同步更新，App Store 官方入口随地区切换。
- **刷新**：顶部刷新按钮加载并刷新全部榜单；每张卡片右上角按钮仅刷新当前榜单，并沿用该卡片当前选择的地区；自动刷新只刷新已加载卡片，刷新使用并发队列且不会重复启动，失败时如有缓存则继续展示缓存数据。
- **主题**：右上角按钮切换深浅主题；首次访问根据系统偏好初始化。
- **免责声明**：页脚按钮打开弹窗，弹窗内包含数据来源、使用提示与责任说明，支持 <kbd>Esc</kbd>、遮罩点击、右上角关闭按钮及「我知道了」四种关闭方式。

## 技术说明

- **技术栈**：HTML5 / CSS3 / JavaScript（ES2020+），无第三方运行时依赖。
- **数据请求**：`fetch` + `AbortController` 超时控制，请求可被新的地区切换取消；首屏附近的卡片在视口加载，滚动/分类/搜索/手动全部刷新时补载，最多 6 路并发；刷新会等待在途任务真实结束，并汇总失败数量。豆瓣与 X 趋势页面通过 `DOMParser` 解析，App Store 使用 iTunes RSS JSON，海外媒体与中国新闻网使用 RSS / Atom XML，新浪、网易、澎湃热榜使用平台 JSON 接口；Codelife 请求带时间戳绕过 CDN 缓存。
- **缓存与渲染**：会话内按 `id + region` 使用 `sessionStorage` 缓存，先渲染缓存再后台刷新；条目读取时统一校验标题与 http(s) 链接，跨日缓存显示日期。列表默认只生成前 10 条 DOM，展开时补全，收起/清空搜索后回收；搜索只统计已加载条目，不再批量 hydrate 每张卡片，并隐藏无命中卡片、提示首屏外的命中位置。刷新保留展开状态和列表焦点。卡片使用 `content-visibility: auto` 跳过视口外渲染，并按骨架/已加载状态分别设置 `contain-intrinsic-size`；骨架屏在未进入视口时暂停动画，主题切换期间临时关闭全页过渡并使用 View Transition 播放主题交叉淡化。
- **安全策略**：`index.html` 通过 meta CSP 限制脚本、样式、字体与 fetch 目标；字体仅允许本站，fetch 目标覆盖 Codelife、Redocly、HN 与 dev.to；并设置 `strict-origin-when-cross-origin`。GitHub Pages 不支持自定义响应头，`frame-ancestors` 等指令仍需反向代理。
- **自动校验**：`scripts/check.mjs` 校验 CSP 哈希与所有 API 主机覆盖、字体文件与子集文本一致性、字体预载、`SHOW` 与折叠 CSS 一致性、46 个榜单配置、唯一 id、默认地区、图标文件和 JS 语法；GitHub Actions 在 push / PR 时运行。
- **渲染**：模板字符串构建卡片，所有远程文本经 HTML 转义后输出，外部链接仅允许 http/https；骨架屏占位，`IntersectionObserver` 实现滚动浮现。
- **分类与地区**：分类标题按钮通过 `aria-expanded` / `aria-controls` 控制对应网格；分类筛选使用 `role="group"` + `aria-pressed` 按钮；地区选择器按当前 `region` 重新请求数据，并同步卡片副标题，App Store 同时更新官方链接。
- **主题系统**：CSS 自定义属性 + `data-theme`，`<head>` 内联脚本在样式加载前确定主题；手动切换先抑制逐元素过渡，支持的浏览器通过 View Transition 进行主题交叉淡化，不支持时使用双 `requestAnimationFrame` 降级为瞬时切换；`prefers-reduced-motion` 下直接切换。`color-scheme` 与 `theme-color` 随主题更新。
- **性能统计**：Navigation Timing API 计算本次加载耗时；运行时长按 `SITE_BIRTH` 实时计算。
- **可访问性**：语义化标签、`aria-label` / `aria-live`、键盘焦点样式，移动端主要触控目标不小于 44px，并在 `prefers-reduced-motion` 下关闭动效。
- **字体**：ZCOOL QingKe HuangYou 与 JetBrains Mono 均为本地自托管：ZCOOL 只包含当前展示文案所需的字符子集（约 41KB），JetBrains Mono 使用 latin 400/700（各约 21KB）。字体文件与 OFL 许可证存放在 `fonts/`，`<head>` 直接 `preload` 字体文件，`@font-face` 写在 `hot.css` 中，不再请求字体 CDN。新增或修改平台名称、分类名等展示文案后，运行 `node scripts/build-fonts.mjs` 重新生成子集；`check.mjs` 会校验子集与当前文案一致。正文仍使用系统中文无衬线字体回退。

**浏览器兼容性**：建议使用较新版本的 Chrome、Edge、Safari 或 Firefox。页面使用了 `color-mix()`、`content-visibility`、`:has()`、View Transitions、`dvh`、`backdrop-filter`、`@starting-style` 等现代 CSS / 浏览器特性，旧版浏览器可能缺少部分视觉效果，但核心功能不受影响。

**已知限制**：

- 主题切换的交叉淡化动画依赖 View Transitions API；不支持的浏览器会直接切换颜色，功能不受影响。
- 搜索为客户端过滤，只覆盖已加载的榜单标题；进入搜索会补载未加载榜单，无命中卡片暂时隐藏，结果会随加载逐步出现。搜索会跳过处于错误状态的榜单，避免重复请求，可在错误卡片内手动重试。搜索直接基于完整数据统计，不会为每张卡片展开全部 DOM；命中在首屏 10 条之外时需按卡片内提示展开查看。
- 展示字体使用按当前静态文案生成的字符子集；新增平台名称、分类名或展示文案后需运行 `node scripts/build-fonts.mjs` 重新生成，否则新字符会回退到系统字体。构建脚本需要访问 Google Fonts 与 jsDelivr。
- 首屏只加载视口附近的卡片，其余卡片在滚动、切换分类、展开分类、搜索或手动全部刷新时加载；顶部滚动条只包含已加载榜单的头条。
- 自动刷新只刷新已加载卡片；未加载卡片会在首次进入视口时获取最新数据。
- 视口外卡片的高度由 `contain-intrinsic-size` 估值，首次滚动到尚未渲染的区域时可能出现轻微的高度校正；卡片渲染后会记住实际高度。
- 榜单更新依赖第三方接口，无法保证实时性或长期可用性。Codelife 是第三方聚合，实测其微博热榜快照可能滞后官方；微博官方接口需要特殊请求头和 CORS 代理，纯静态页面无法直接接入。
- 会话缓存仅在当前标签页有效；数据超过 5 分钟后会在后台刷新，刷新失败时保留旧数据并标注日期；关闭标签页后缓存失效。
- 豆瓣、X 趋势、App Store、海外媒体 RSS、新浪热榜、澎湃新闻与中国新闻网依赖公共 CORS 代理；代理或上游不可用时，对应卡片会显示加载失败。
- X 趋势来自 getdaytrends 的全球及国家/地区页面，不展示热度值；getdaytrends 未收录中国大陆等部分地区；条目链接指向 x.com，在中国大陆访问该站点可能需要额外的网络条件。
- App Store 榜单来自 Apple iTunes RSS，地区名称与条目内容由 Apple 返回；不同地区商店的上架情况可能存在差异。
- 海外媒体卡片来自各媒体官方 RSS，内容多为英文，更新频率与排序由来源决定；RSS 或代理不可用时卡片会显示加载失败。
- 新浪热榜、网易新闻、澎湃新闻与中国新闻网使用平台公开接口或 RSS，接口调整、限流或代理不可用时对应卡片会显示加载失败。
- 站点运行时长基于固定起始时间计算，不代表服务器监控数据。
